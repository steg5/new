# GRYNTSIV

Android-проєкт карткової гри GRYNTSIV. Початкова версія 0.1.0.

## Відкриття
1. Завантажте ZIP і розпакуйте.
2. Створіть GitHub-репозиторій та завантажте в нього всі файли.
3. Відкрийте проєкт в Android Studio або запустіть GitHub Actions.
4. Для локальної збірки потрібен JDK 17 та Android SDK 35.

## Поточний стан
Це стартовий каркас: Android/Compose UI, базовий рушій карт, підрахунок очок, параметри тем і автоматичного пасу, Gradle та workflow.
Мережеве створення кімнат, синхронізація гравців, передавання ведучого, збереження історії, повна логіка накладання карт, боти та смайлики ще потребують реалізації й тестування. Екрани приєднання та історії наразі є заглушками. Не використовуйте цю збірку як завершену мережеву гру.

## Правила, закладені в рушій
- 7 карт на старті.
- Очки: +2/Skip/Reverse = 20; Wild/+4 = 50; цифрові = номінал.
- Переможець отримує 0, інші отримують суму карт на руках.
- Не потрібно оголошувати UNO.
